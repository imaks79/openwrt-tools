# openwrt-tool

Скрипт `install.sh` разворачивает на роутере с прошивкой OpenWrt (apk-сборки,
23.05+/24.10+) типовую конфигурацию: обновление системы, AdGuard Home,
podkop, тему LuCI и сетевые/сетевые UCI-настройки — всё в один проход,
без ручного вмешательства между шагами.

## Как это работает

Исходные шаблоны настроек лежат в `Шаблоны/`:
- `adguardhome.md` — конфиг `/etc/adguardhome/adguardhome.yaml`;
- `Конфигурация cudy tr3000.md` — три блока команд (обновление системы,
  установка пакетов, сетевые UCI-настройки).

`install.sh` объединяет всё это в один файл. Особенность в том, что первый
блок команд заканчивается перезагрузкой роутера — простой `wget | sh` этого
не переживёт. Поэтому скрипт:

1. при первом запуске сохраняет себя в `/root/openwrt-tool/install.sh`;
2. хранит прогресс в `/etc/openwrt-tool.stage` (`1` → обновление,
   `2` → пакеты и конфиги, `3` → готово);
3. перед каждой перезагрузкой регистрирует одноразовый хук в `/etc/rc.local`,
   который вызывает сохранённую копию скрипта после старта системы;
4. после последнего этапа хук из `rc.local` удаляется.

Итого роутер сам уходит на 2 перезагрузки и полностью настраивается без
повторных заходов по SSH.

## Настройка перед публикацией на GitHub

В `install.sh` замените плейсхолдер `SCRIPT_URL`:

```sh
SCRIPT_URL="https://raw.githubusercontent.com/<USER>/<REPO>/main/install.sh"
```

на реальный raw-адрес файла в вашем репозитории (нужен, чтобы скрипт мог
скачать сам себя для повторного запуска после перезагрузки).

Конфиг AdGuard Home в скрипте использует плейсхолдер `REPLACE_WITH_YOUR_BCRYPT_HASH`
вместо пароля — перед использованием сгенерируйте свой хэш и подставьте его:

```sh
htpasswd -bnBC 10 "" 'ваш_пароль' | cut -d: -f2
```

и вставьте результат в `password:` внутри `install.sh`. Не коммитьте реальный
хэш в публичный репозиторий.

## Запуск на роутере

Базовый вариант (hostname по умолчанию `cudy_router`):

```sh
wget -O - https://raw.githubusercontent.com/<USER>/<REPO>/main/install.sh | sh
```

С уникальным именем роутера (полезно при массовой настройке нескольких
устройств одновременно):

```sh
wget -O /root/install.sh https://raw.githubusercontent.com/<USER>/<REPO>/main/install.sh
HOSTNAME=router-05 sh /root/install.sh
```

## Логи и повторный запуск

Ход выполнения пишется в `/root/openwrt-tool/install.log`. Если нужно
прогнать настройку заново с начала:

```sh
rm -f /etc/openwrt-tool.stage
sh /root/openwrt-tool/install.sh
```

## Отличие от исходных шаблонов

- Настройки собраны в один файл — не нужно вручную копировать YAML на роутер.
- Добавлено ожидание сети (до ~60 сек) перед каждым `apk update`, так как
  после ребута интернет поднимается не мгновенно.
- Установка `podkop` и темы LuCI обёрнута так, чтобы их сбой не прерывал
  остальную настройку (AdGuard Home и сетевые параметры всё равно применятся).
- Добавлен `uci commit attendedsysupgrade` — в исходном шаблоне опция
  `login_check_for_upgrades` выставлялась через `uci set`, но не коммитилась
  и поэтому не сохранялась.
- Hostname можно переопределить через переменную окружения `HOSTNAME`.
